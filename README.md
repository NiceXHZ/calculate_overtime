# 加班时长计算器

一个无需安装的纯前端工具：导入 JSON 打卡记录，计算本月加班时长，并可新增、删除和导出记录。

所有数据只在浏览器本地处理，不会上传。

## 快速使用

1. 用现代浏览器打开 `index.html`。
2. 点击或拖放 JSON 文件，等待页面显示「已加载」。
3. 点击「计算加班」查看本月统计和每日明细。
4. 点击「管理数据」新增或删除打卡记录。
5. 修改后点击「保存并导出新文件」。

可以使用 [overtime_log.example.json](./overtime_log.example.json) 体验。页面不会覆盖原文件；未导出的修改会在刷新或关闭页面后丢失。

## 计算规则

仅统计设备当前月份的记录。

| 日期 | 加班时间 |
| --- | --- |
| 周一至周五 | 最后一次打卡晚于 17:30 时，计算 17:30 至该次打卡的时长 |
| 周六、周日 | 至少有两次打卡时，计算最早与最晚打卡的时间差 |

注意：

- 打卡时间会自动排序。
- 有记录但加班为 0 的日期也计入「记录天数」。
- 仅按星期判断工作日和周末，不识别节假日或调休。
- 不扣除午休、晚餐及中途离开时间，也不自动配对上下班打卡。
- 不允许跨 0 点计算；打卡时间的本地日期必须与所属日期一致。
- 日期和时间均按浏览器本地时区处理，建议在北京时间环境中使用。

## JSON 格式

推荐使用日期对象和 ISO 时间字符串数组：

```json
{
  "2026-09-10": {
    "entries": [
      "2026-09-10T09:00:00+08:00",
      "2026-09-10T19:00:00+08:00"
    ]
  }
}
```

兼容以下 `entries` 格式：

- 单个或多个带时区的 ISO 时间字符串；
- 单个或多个 Unix 毫秒时间戳；
- ISO 字符串与毫秒时间戳组成的混合数组。

导入后，记录会统一转换为按时间排序的 ISO 字符串数组。时间字符串中的秒和毫秒精度会保留，重复打卡不会自动删除。

日期键必须为有效的 `YYYY-MM-DD`；数字必须是安全整数形式的毫秒时间戳；ISO 字符串必须包含 `+08:00`、`Z` 等时区信息。打卡时间转换到浏览器本地时区后，日期必须与所属日期键一致。

格式无效、误用秒级时间戳或包含跨日打卡的文件会加载失败，并清空当前数据，避免产生错误统计。

## 数据管理

- 加载 JSON 后才能打开编辑器；加载空对象 `{}` 可从零开始录入。
- 编辑器仅显示和新增本月记录，导出时会保留其他月份的数据。
- 点击某天的「删除」可选择删除一条打卡，或删除当天全部记录。
- 删除单条记录后会停留在当天列表，方便连续操作；日期对象及其额外字段会保留。删除当天全部记录会移除整个日期对象。
- `entries: []` 会保留在导出文件中，但不参与统计。
- 新增或删除后，统计结果会自动刷新。

## iOS 快捷指令

安装：[打卡快捷指令](https://www.icloud.com/shortcuts/1d4ad7c1eae14dbb964682359b14b8fc)

每次运行会将当前时间以带时区的 ISO 格式追加到 `iCloud Drive/Shortcuts/overtime_log.json`。网页可直接导入该文件；编辑并导出后，需自行用新文件替换原文件。
