# 设备验收清单

适用于加班打卡 **0.3.6**。自动化测试覆盖计算、存储与界面回归，本清单补充真实设备上的图形、触感和桌面行为。

## 界面与网页风格

- [ ] 四个页面位置和操作入口与旧版一致；浅色主卡、深色文字、按钮、卡片边界和浮动导航均清楚可读。
- [ ] 窄屏及 1.6 倍字体下，月份、补录／导入按钮和六种小组件尺寸不换行，较长数字不截断。所有内容可滚动到导航上方操作。
- [ ] 横屏和宽屏内容居中，导航不拉伸过宽；切页保留各页滚动位置。
- [ ] 月历对齐周一至周日，今天描边；有记录日期可打开每日详情，空白及无记录日期不误触发。
- [ ] 设置里的分段外观选择与系统深浅色正确切换，关闭液态玻璃后仍保留统一样式；在真实设备上验收滚动和玻璃折射流畅度。

## 安装与数据安全

- [ ] 从 Releases 的 Assets 下载正式 APK，确认可正常安装，应用版本与发布说明一致；源码归档不作为安装包。
- [ ] 新安装打开后可直接打卡，无需先创建或导入文件。
- [ ] 使用相同签名覆盖升级后，记录与设置保留。
- [ ] 切换 debug / release 或卸载之前，先导出完整 JSON，确认外部备份有效，再自行卸载、安装和导入。

有 ADB 环境时，可在 `android/` 中执行；也可复制 APK 到设备自行安装：

```bash
adb install -r app/build/outputs/apk/debug/app-arm64-v8a-debug.apk
```

## 打卡、计算与备份

- [ ] 打卡后强制结束应用，重开仍保留。连点只记一次，达到 3 秒后可再次记录；组件、磁贴和应用共享间隔。
- [ ] 「撤销」仅删除对应那次打卡；删除记录后可恢复最近修改前副本。恢复前先导出当前完整备份。
- [ ] 补录普通工作日 09:00 / 19:00，默认计算 1.5 小时；普通周末 09:00 / 18:00 计算 9 小时，并核对法定假日与周末调休上班日。
- [ ] 修改工作日下班时间后，统计按新设置计算；切换月份查看正确。
- [ ] 导入仓库示例 JSON，查看 2026 年 9 月；重复导入不增加记录，无效文件不覆盖原数据。
- [ ] Android 导出 JSON 后网页可导入，网页导出后 Android 可合并导入；核对月份、额外字段与毫秒。CSV 在表格软件中正常显示中文。
- [ ] 断网仍能打卡、补卡、查看和导出。已缓存或内置年份正确分类；未知年份提示暂按星期规则计算。

## 弹层与滚轮

- [ ] 补卡打开即能看到操作区和保存按钮，无需向上拖动；浅色、深色、窄屏、横屏与放大字体下按钮完整可用。
- [ ] 日期摘要 `yyyy/MM/dd` 与时间保持单行。滚动年、月、日、小时和分钟后，中央选中项、摘要和保存结果一致；未来时间不能保存。
- [ ] 从 31 日切到 2 月或 4 月，以及切换闰年时，日期自动变为有效值。
- [ ] 快速滑动后惯性吸附正常，停稳后能保存。刻度音效和轻震动仅在选择值变化时触发，打开弹层不会自动响或震动。
- [ ] 两项滚轮反馈分别关闭后，重启仍保持。系统静音或关闭触摸音效后不发声，系统关闭触感后不强制震动。
- [ ] 补卡、下班时间、每日记录、删除和恢复确认的材质一致。返回键、遮罩、关闭按钮、顶部下拉均可关闭；删除取消后回到原记录详情。
- [ ] 弹层打开时，点按底层页面不会打卡或切换页面。
- [ ] 补卡、详情、确认和小米帮助页均平滑滑入滑出；保存、完成、取消不会瞬间消失。连续点击确认只执行一次，取消后立刻点确认不会执行操作。
- [ ] 顶部短距离下拉回弹，回弹中再次拖动保持跟手，向下拖足够距离后关闭；滚动内容或滚轮不会拖走整个面板。关闭按钮无自动焦点高亮，键盘仍能正常导航。
- [ ] 页面和日期／时间切换有舒缓过渡，快速切换后内容与选中页一致；系统动画时长为 0 时，退出仍完成且操作只执行一次。

## 桌面组件与快捷磁贴

- [ ] 每种小组件打卡成功显示保存时间，系统允许时轻震一次；3 秒内重复点击只提示，不播放成功震动。重开应用确认确实保存。
- [ ] 关闭「快捷打卡震动」后只显示文字，滚轮触感开关不受影响；重启应用仍保持。系统触感关闭、静音、勿扰或设备没有马达时不影响保存和提示。
- [ ] 分别记录小米／Redmi／POCO、华为 Android／EMUI、OPPO、vivo／iQOO、三星等真实设备的系统版本、桌面版本及后台触感结果；系统抑制后台震动时仍须能通过 Toast 和更新时间确认打卡，不以自动化结果代替真机验证。
- [ ] 从设置请求添加组件：桌面确认成功后显示成功提示，不再弹出帮助；请求发出约 6 秒仍未确认时，在前台可见「尚未确认添加成功」。后台和其他弹层打开时不抢占界面。
- [ ] 小米手机上，兜底弹窗离线展示官方流程图；点图放大、双指缩放、拖动和按钮缩放均可用。返回提示再关闭后不反复弹出；手动添加同一尺寸后回到应用可识别成功。
- [ ] 添加 2×1、2×2、3×2、4×1、4×2、4×3 六种组件，分别检查深浅色；时间、记录和按钮层次清楚。
- [ ] 试用接近正方形的 2×2，并放大系统字体；时间和按钮不裁切，较早记录按空间减少。
- [ ] 主时间与秒数基线对齐，较早记录按最近优先排列；点按记录可查看今日全部打卡。
- [ ] 在每种组件中，只有专用打卡按钮新增记录，点击时间或背景只进入今日页面；特别检查 2×1。
- [ ] 打卡后提示成功，应用与各组件出现同一条记录；应用在后台或进程被回收后，组件仍可打卡。
- [ ] 缩放组件、旋转桌面后排版更新；特别检查不提供精确尺寸列表的桌面。若更新应用后仍显示旧缓存，缩放一次触发刷新。
- [ ] 跨午夜、更改手机时区和设备重启后组件刷新，分组仍按北京时间；留意厂商对周期刷新的延迟。
- [ ] 添加快捷设置「记录打卡」磁贴，锁屏时先解锁，再确认实际保存。

## 应用图标快捷入口

- [ ] 更新后打开应用一次，长按应用图标能看到「记录打卡」「补录打卡」「查看记录」；数量以桌面支持上限为准，三个图标清晰可辨。
- [ ] 从冷启动和已有应用页面分别使用三个入口：打卡一次、补卡打开滚轮、记录进入上次选择的月份。普通应用图标不自动打卡。
- [ ] 连点打卡遵循 3 秒保护，保存结果可撤销。旋转、应用重建、按 Home 后从最近任务返回均不再自动打卡。
- [ ] 补卡面板中修改日期／时间后，再次选择补卡入口，输入保留；其他面板打开时选择查看记录，可正常进入记录页。
- [ ] 支持的桌面把入口拖成独立快捷图标后可再次使用；不支持快捷菜单的桌面仍可用应用、组件或磁贴打卡。锁屏情况下不绕过解锁写入记录。

## 图形与兼容性

- [ ] Android 12+ 模糊正常，Android 13+ 折射正常，关闭玻璃后文字仍清晰；低内存设备或旧版系统采用不透明材质。
- [ ] 连续滚动列表、滚轮和切换页面时无明显卡顿；音效与震动强度适中。
- [ ] Android 8–11 的本地记录、组件与文件导入导出可用。
