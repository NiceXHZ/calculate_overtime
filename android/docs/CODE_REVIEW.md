## 已修复的逻辑与边界

1. **午夜 3 秒防重复**：旧逻辑只检查当天最后一条。现在比较相邻日期的近时刻记录，覆盖跨午夜、时间回拨和混入未来记录的情况；恰好 3 秒允许再次打卡。
2. **过期删除确认**：确认时校验原记录时间；列表发生变化时提示重新选择，避免按旧下标误删。
3. **过期撤销**：打卡结果携带保存版本；补卡后又删除、导入、恢复或打卡，旧撤销不再删除相同时间的其他记录。无变化的重复导入不会使撤销失效。
4. **恢复行为**：恢复健康数据前保留当前副本，可再次恢复撤回；读取失败时单独保留损坏原件，不将健康文件都累积为 damaged 文件。
5. **副本与写入失败**：副本先写临时文件并同步，再改名；恢复跳过未完成/无效副本。副本排序不依赖系统时间持续递增。原子写失败不改变内存或原文件，也不会靠反复重试累积副本。
6. **无变化的导入**：不重写文件或轮换副本，保留有意义的恢复历史。
7. **CSV 月份**：保存的是打开文件选择器时的月份，数据读取显式使用该月份和对应年节假日；乱序输入的首末打卡仍正确。
8. **节假日**：拒绝错误年份、空目标年份、非布尔类型；合并下一年通知对十二月的修正；下一年通知缺失不丢弃本年有效数据。切换月份不等待旧 HTTP 请求，也不会由旧年份响应覆盖当前年份。
9. **JSON**：Android 接受 UTF-8 BOM；两端不误拒绝 Unix 纪元附近的合法毫秒值。网页拒绝可能被 Date 规范化的 24:00 等无效时间，并完整保留 `__proto__` 额外字段。
10. **历史时区**：上海早期曾有秒级偏移，导出这些时间时使用兼容的毫秒整数，避免备份往返产生数十秒偏移。
11. **读取限制**：本地记录/恢复最多读 8 MB，节假日最多读 1 MB；网页对超限文件在读取前拒绝。流读取可应对返回 0 的数据提供者。
12. **系统外部入口**：无浏览器时打开项目链接显示提示，避免 ActivityNotFoundException 导致退出。

## 运行效率与资源

- 界面时钟由每秒更新改为按分钟边界更新，最后一个前台订阅停止后取消计时，返回应用立即读取当前时间；不常驻秒级循环。
- 月度统计放在后台计算，输入未变时不重复统计；工作日/休息日计算直接取首末值，避免为汇总重新排序整个列表。
- 合并使用日期索引，消除对每个日期反复线性查找。保留日期排序及原有重复次数规则。
- 今日时间线和每日详情按需创建可见行。记录卡最多预览 8 条，完整记录仍可在详情滚动查看；加入 1,000 条记录的滚动与惰性渲染检查。
- 没有组件时提前跳过组件读取和排版；有组件时仅传入最多 19 条可显示记录。更改音效、震感或下班时间不再触发无关组件刷新。

完整 JSON 与修改前副本仍会随文件大小增加而增加写入量；上限为单文件 8 MB、10 个普通副本。这个规模下保持原子保存与可恢复性，避免为了减少写入引入数据库迁移风险。损坏原件单独保留，不自动删除。

## 单文件与平台构建

原包包含四套 `libandroidx.graphics.path.so`。现在分别生成四种 ABI 的**独立完整 APK**，并额外提供通用 APK；每次只需安装一个文件。所有平台使用同一包名、版本和正式签名。

| 文件后缀 | 大小（字节） | 用途 |
| --- | ---: | --- |
| `arm64-v8a.apk` | 1,104,363 | 常见 64 位 ARM 手机 |
| `armeabi-v7a.apk` | 1,101,521 | 32 位 ARM 系统 |
| `x86_64.apk` | 1,105,024 | 64 位 x86 Android 系统 / 模拟器 |
| `x86.apk` | 1,103,545 | 32 位 x86 Android 系统 / 模拟器 |
| `universal.apk` | 1,154,436 | 包含以上四套库，兼容备用 |

ARM64 包相对旧 0.3.1 通用包 1,244,620 字节减少约 **11.3%**；其中单平台拆分相对本次通用包减少约 **4.3%**。原生库本身很小，包体主要是共享字节码；拆包减少下载/安装体积，不将其夸大为业务运算速度提升。

按 [Android 官方 ABI 拆包方案](https://developer.android.com/build/configure-apk-splits)构建，未使用需要另外安装 base/config APK 的分发形式。对齐检查依据 [Android 16 KB 页大小要求](https://developer.android.com/guide/practices/page-sizes)。

打包脚本逐包验证签名、非调试标记、实际包名与版本、ABI 内容，以及 16 KB ZIP / 64 位 ELF LOAD 段对齐。APK、`SHA256SUMS.txt` 与 `PACKAGE_REPORT.json` 位于忽略的 `app/build/release-assets/v0.3.2/`。签名身份仍保留在仓库之外。
