# 网页改造与复查记录

日期：2026-10-15。范围为网页、静态构建及相关文档，Android 源码与安装包未改动。

## 本次结果

网页改为浅色 / 深色液态玻璃工作台，增加跨月热力图、日记录详情、历史补录、撤销、记录筛选、下班时间设置、月度 CSV、浏览器草稿恢复与冲突提示。原有 JSON 校验、额外字段、历史月份、毫秒和重复记录兼容性保留。

数据计算、节假日加载、界面交互和轻量折射分文件维护。生产产物只包含静态页面与资源，没有运行时框架依赖。

## 复查中处理的问题

- 保留损坏替换文件之前的有效数据；导入、月份和下班时间改变后，旧异步节假日响应不能覆盖新结果。
- 文件读取失败时恢复此前仍在等待的计算，避免按钮一直禁用；重复选择同一文件在取消确认后仍有效。
- 删除按文档版本和实际时间校验，撤销仅恢复最近一次修改；从嵌套详情重新打开补录时，旧关闭事件不能隐藏新弹层的辅助技术状态。
- 拒绝未来、重复和夏令时无效补录。空日期、原有重复、历史偏移秒数、附加字段和毫秒均可导出回读。
- 原文件及规范化后的数据均限制为 8 MB；超限补录回滚，临界备份使用紧凑 JSON，CSV 对公式文本转义。
- 草稿失败不显示为成功；检测到其他标签页更新后暂停覆盖，支持的环境通过 Web Locks 串行写入。
- 修正页脚与深色悬停按钮的对比度，窄屏、横屏保持保存按钮可见；使用原生模态对话框完成焦点限制、返回和 Escape 关闭。

## 性能与适配

热力图最多 31 个日期单元，月度明细最多 31 天，超长日时间线首次渲染 100 条。计算首末时间使用单次遍历，不对大数组做参数展开；回归包含十万次打卡。

大面积卡片使用轻量半透明材质，仅顶部和底部导航生成有界折射图。背景采用静态渐变，不克隆页面内容、交互控件或大阴影；打开弹层时暂停背后折射。位置与尺寸没有变化时复用滤镜，空闲时没有持续动画循环。WebKit 复查中发现的大面积模糊开销已通过上述范围收敛处理。

系统减少动态效果、减少透明度及强制对比度均有降级；用户可以关闭玻璃效果，日期格仍以文字说明时长与状态。

## 验证结果

- `npm test`：**54 项通过**，包括 33 项原有回归的延续，以及月份、状态竞争、撤销、文件边界和导出回读测试。
- Chromium / Firefox / WebKit：每种 **16 项，共 48 项通过**，运行中未发现未捕获的页面错误。
- 深浅色、对比度与焦点流程另行复核；截图前明确等待主题切换完成，避免把尚未切换的画面当作深色覆盖。
- 视口覆盖 320×568、390×844、768×1024、1440×1000 和 667×375 横屏；检查页面横向溢出、操作栏与弹层保存区域。
- axe 检查主界面与补录弹层的 WCAG 2 A / AA、2.1 AA 相关规则，所测场景无违规项。
- `npm run build` 通过，所有页面相对资源可解析；生成的 `dist/index.html` 在三个引擎中直接以 `file://` 打开并载入示例，计算均为 3 天 / 10.5 小时，无未捕获错误。
- 本地预览服务检查正常资源可访问，Android 本机配置不可访问，编码路径穿越与空字节请求被拒绝。

自动化 WebKit 不等同于 iPhone 真机，文件下载最终保存、系统日期面板和触屏手感仍取决于设备。浏览器草稿不能替代独立备份；详细操作与限制见 [网页说明](WEB.md)。
