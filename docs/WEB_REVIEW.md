# 网页改造与复查记录

日期：2026-10-15。范围为网页、静态构建及相关文档，Android 源码与安装包未改动。

## 本次结果

网页改为浅色 / 深色液态玻璃工作台，增加跨月热力图、日记录详情、历史补录、撤销、记录筛选、下班时间设置、月度 CSV、浏览器草稿恢复与冲突提示。原有 JSON 校验、额外字段、历史月份、毫秒和重复记录兼容性保留。

数据计算、节假日加载、界面交互和轻量折射分文件维护。生产产物只包含静态页面与资源，没有运行时框架依赖。

## 复查中处理的问题

- 保留损坏替换文件之前的有效数据；导入、月份和下班时间改变后，旧异步节假日响应不能覆盖新结果。
- 文件读取失败时恢复此前仍在等待的计算，避免按钮一直禁用；重复选择同一文件在取消确认后仍有效。
- 删除按文档版本和实际时间校验，撤销仅恢复最近一次修改；从嵌套详情重新打开补录时，旧关闭事件不能隐藏新弹层的辅助技术状态。
- 拒绝未来、重复和夏令时无效补录。空日期、原有重复、历史偏移秒数、附加字段和毫秒均可导出回读。
- 原文件及规范化后的数据均限制为 8 MB；超限补录回滚，临界备份使用紧凑 JSON，CSV 对公式文本转义。
- 草稿失败不显示为成功；检测到其他标签页更新后暂停覆盖，支持的环境通过 Web Locks 串行写入。
- 修正页脚与深色悬停按钮的对比度，窄屏、横屏保持保存按钮可见；使用原生模态对话框完成焦点限制、返回和 Escape 关闭。

## 性能与适配

热力图最多 31 个日期单元，月度明细最多 31 天，超长日时间线首次渲染 100 条。计算首末时间使用单次遍历，不对大数组做参数展开；回归包含十万次打卡。

大面积卡片使用轻量半透明材质，仅顶部和底部导航生成有界折射图。背景采用静态渐变，不克隆页面内容、交互控件或大阴影；打开弹层时暂停背后折射。位置与尺寸没有变化时复用滤镜，空闲时没有持续动画循环。WebKit 复查中发现的大面积模糊开销已通过上述范围收敛处理。

系统减少动态效果、减少透明度及强制对比度均有降级；用户可以关闭玻璃效果，日期格仍以文字说明时长与状态。

## 2026-10-16：iOS 27.2 Beta 图标兼容处理

用户在帽子云站点反馈：网页图标正常，添加到主屏幕却只显示灰色「加」。检查该站点的 HTML、PNG 和 Manifest 均为最新文件，图片返回 200 且类型正确；公开的同版本实测反馈指出，内嵌 `apple-touch-icon` 可以绕过添加面板的图片网络请求。本次采用该方案，尚未确认 Apple 系统缺陷的具体原因。

- 构建及本地预览共用同一处理函数，从现有 PNG 自动生成 180 像素图标的 data URL；源 HTML 和原始 PNG 保持分离，普通图标及 Manifest 图标继续提供。
- 内嵌图标字节与 PNG 完全一致，构建 HTML 仅替换该图标链接，增加 27,420 字节；本机 gzip 比较增加约 21.4 KiB，不增加页面运行时逻辑或依赖。
- `npm test` **55 项通过**，新增隔离目录中的实际构建检查，验证内嵌图标、源文件未改写和输出资源完整。
- Chromium / Firefox / WebKit 的桌面名称与图标专项回归共 **3 项通过**：内嵌图片在独立图标 URL 被阻断时仍可解码，180 / 192 / 512 像素图片尺寸及不透明度正确，名称保持固定。
- `npm run build` 通过。兼容效果仍需对应 iOS 27.2 Beta 真机重新添加确认；此次自动化不包含系统分享面板。

## 2026-10-21：面板过渡与下拖关闭

- 五类网页面板（月份、补录、当天记录、设置、确认）统一使用 480 ms 滑入、滑出，遮罩同步渐变。移动端从屏幕下方进入，宽屏使用较短位移。缓动降低前段位移速度，避免动画体感接近闪现；时长从统一 CSS 变量读取。
- 顶部横条扩大到 80×28 像素的拖动区域，下拉跟随指针，达到距离阈值或快速下甩时关闭，否则回弹。内容区域仍可滚动；取消手势、指针捕获丢失、切入后台、失焦及旋转窗口会清理拖动状态。
- 去掉日期输入框的自动聚焦，面板打开时先聚焦标题；日期和时间控件由用户主动点按。非交互标题不显示蓝色焦点框，触摸/鼠标操作不遗留按钮焦点外圈，键盘 Tab 导航保留可见焦点。
- 关闭完成后再退出原生模态状态，避免动画未结束就放开背景交互；重开会取消自身旧动画，防止旧回调关闭新面板。叠层查看时原面板轻微后退，返回时恢复，保持子面板完整的退出过渡。系统「减少动态效果」开启时直接完成过渡。
- 月历、记录筛选、日记录更新与提示条使用 280 ms 内容过渡，按钮反馈为 220 ms，短拖回弹为 360 ms。通知重复显示及中途更新会复用当前状态，旧关闭回调不会隐藏新提示；运行中开启「减少动态效果」也会结束正在播放的动画。
- 单独提高面板底色遮挡度，保留玻璃边缘与半透明材质，减轻背景文字透出对阅读的干扰。动画期间才启用合成提示，结束后清理，无常驻动画循环或新增运行时依赖。
- `npm test` **55 项通过**；Chromium / Firefox / WebKit 每种 **26 项，共 78 项通过**。其中面板专项共 24 项，覆盖所有面板的过渡、短拖回弹、长拖关闭、手势中断、内容滚动、未保存输入保留、重开竞争、嵌套替换、焦点和减少动态效果；新增检查动画前四分之一的实际位移、指针/键盘焦点差异、记录筛选及提示动画竞争。
- 视觉调整后另行通过三个引擎的面板过渡、深浅色无障碍及 320 / 390 / 768 / 1440 像素宽度和横屏适配复核；`npm run build` 通过。
- 移动版 WebKit 截图检查了动画中间帧与深浅色补录面板；Chromium 移动触摸协议验证实际触摸事件可拖动并关闭面板，关闭后滚动锁解除。截图保存在忽略目录 `artifacts/sheet-review/`，以上均不等同于 iPhone 真机测试。
