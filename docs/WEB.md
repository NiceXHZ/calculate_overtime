# 网页使用与开发

网页提供加班月报、热力图和打卡编辑，使用原生 HTML、CSS、JavaScript。没有运行时框架、字体 CDN 或打卡数据上传服务；可在线使用，也可保留整个目录后直接打开 `index.html`。

## 添加到 iOS 主屏幕

在 Safari 打开在线网页，选择分享 →「添加到主屏幕」。网页名称与桌面名称固定为「加班统计工具」，切换月份不会改变名称。支持「作为网页 App 打开」开关的系统中，保持该开关开启即可使用独立窗口。

桌面图标使用不透明的绿色时钟 PNG，提供 180、192、512 像素版本；iOS 元信息和 Web App Manifest 同时声明名称、图标与独立窗口模式。页面保留缩放能力，并为刘海、横屏安全区域和底部手势条留出空间。

针对 iOS 27.2 Beta 中添加主屏幕仍显示名称首字的反馈，生产构建会自动把 180 像素 PNG 内嵌到 HTML 的 `apple-touch-icon`，避免添加面板单独请求该图片。本地 `npm run dev` 使用相同处理；原始 HTML 仍引用独立图片，直接打开源码时保持原有方式。普通图标文件和 Manifest 图标也继续提供。

这是依据[开发者实测反馈](https://www.reddit.com/r/PWA/comments/1wsruwy/pwa_icon_not_working_on_ios_272beta2/)采用的兼容方案，效果需在对应 iOS Beta 真机确认。自行部署时应运行 `npm run build` 并发布 `dist/`，仅发布仓库原始文件不会包含此处理。

已有入口可能保留创建时的名称和图标。如果更新后仍旧显示异常，先导出 JSON 备份，再移除旧入口，并从 Safari 重新添加。主屏幕网页 App 与 Safari 的草稿存储可能独立，需要通过 JSON 导入已有记录；此适配不新增离线缓存或后台同步。

配置依据：[Apple 主屏幕名称、图标与独立窗口说明](https://developer.apple.com/library/archive/documentation/AppleApplications/Reference/SafariWebContent/ConfiguringWebApplications/ConfiguringWebApplications.html)、[WebKit 主屏幕网页 App 说明](https://webkit.org/blog/17333/webkit-features-in-safari-26-0/)。

## 从记录开始

- **导入 JSON**：点击导入或拖放文件，载入后自动计算。本月有记录时优先显示本月，否则显示最新的有记录月份。完整校验通过后才替换当前数据，损坏文件不会覆盖已载入的工作区。
- **体验示例**：离线载入仓库公开示例，方便了解界面与规则。文件名明确显示为示例。
- **新建记录**：从空工作区开始补录，无需事先创建 `{}` 文件。记录暂存在浏览器，导出 JSON 后才有独立的外部文件。

切换文件前若有未导出的更改，会先询问；尚未恢复的未导出草稿也会受到替换确认保护。

## 月报、热力图与明细

月份控件可前后切换，也可按年份选择任意月份；有记录的月份会标出圆点，并提供最近月份快捷入口。「回到本月」按浏览器当前日期定位，不会在跨午夜时强行改变正在查看的历史月份。

四项统计分别为总加班小时、记录天数、加班天数和平均加班时长。平均值只除以有加班的日期，计算保留秒和毫秒，界面小时数按一位小数显示；CSV 提供计算秒数及更精细的小数小时。

热力图从周一开始排列，每个日期显示记录状态或简短时长。颜色固定分档，不随当月最大值变化：

| 颜色档位 | 时长 |
| --- | --- |
| 最浅 | 无加班 |
| 1 | 大于 0、少于 1 小时 |
| 2 | 1 至不足 3 小时 |
| 3 | 3 至不足 6 小时 |
| 4 | 6 小时及以上 |

无记录显示横线，有记录但未加班显示「已记录」。休息日只有一次打卡时标为「待补全」，不把它误算成整天加班。颜色之外仍提供可读时长、提示与完整的辅助技术标签。

点按日期或明细进入当天时间线，查看秒与毫秒、补录、删除单条或整天记录。超长时间线首次显示 100 条，可继续加载。明细可筛选全部、有加班、待补全，并切换时间排序；筛选不会改变整个月的汇总。

## 编辑、撤销与备份

补录范围是当前查看月份，可以回看历史月份；未来时间、夏令时跳过的本地时间和完全相同的已有打卡不能新增。导入文件中的原有重复记录、额外字段和空日期仍会保留。

删除需要玻璃确认弹层。删除单条记录保留当天附加字段；删除整天会一并移除附加字段，确认窗口会说明。撤销只作用于最近一次修改，后续修改和导入会使旧撤销失效；日期详情中也提供撤销入口。

- **导出备份**：包含所有月份及额外字段的完整 JSON，不覆盖原文件。生成下载后请确认下载确实完成。
- **导出 CSV**：仅包含当前月份，保留日期类型、打卡次数、首末时间、计算秒数、下班时间、时区与待补全说明。CSV 适合查看报表，不能替代完整 JSON 备份。
- **容量限制**：原文件和规范化后的完整 JSON 上限均为 8 MB；接近上限时使用紧凑 JSON 导出，超过上限的新增操作会回滚。

记录更改会尝试暂存至当前浏览器，下次打开时由用户选择恢复。浏览器存储不足、私密浏览限制或清理网站数据可能导致草稿不可用；界面不会把失败暂存显示为成功。检测到其他标签页更新草稿后，本页会停止覆盖并提示先导出；支持 Web Locks 时对跨标签页写入加锁，不支持时使用写入前比对和存储事件检测。

草稿与偏好属于当前网站、浏览器和设备，不会自动同步，也不会改变 iOS 快捷指令正在使用的源文件。直接用 `file://` 打开时，存储能力取决于浏览器，独立导出仍可使用。

## 外观与计算设置

支持浅色、深色和跟随系统，可关闭玻璃效果。顶部外观按钮可快速切换深浅色。折射只在小范围导航控件上绘制，打开弹层时暂停背后的折射；静止时没有持续动画循环。系统要求减少动态效果或减少透明度时会相应降低效果。

月份、补录、当天记录、设置和确认面板采用统一舒缓的滑入、滑出过渡。从补录查看某天时，原面板会轻微后退，返回时连贯恢复。拖动顶部横条可向下关闭，轻拖后松手会回弹；拖动仅作用于横条，面板内容仍可正常滚动。也可使用关闭按钮或 Escape 退出。打开补录时焦点停在标题，点击日期或时间后才进入系统选择器。触摸操作不显示按钮焦点外圈，键盘导航保留焦点提示。

月份内容、记录筛选、日记录更新及提示条提供轻量过渡，重复提示不会因旧的关闭动画而消失。系统开启「减少动态效果」时省略自动过渡，下拖操作仍可使用。

工作日下班时间默认 17:30，可在偏好设置修改。休息日按首末打卡间隔计算，不扣午休、不自动配对、不合并跨日。网页使用浏览器本地时区，并在页面上显示；与 Android 结果对比时，应确认时区和下班时间一致。

内置 2025、2026 年安排供离线使用，其他年份尝试联网获取。网络失败保留缓存或内置安排；完全无数据时明确提示按星期规则计算。偏好设置提供主动刷新入口。

## 本地开发与部署

```bash
npm ci
npm run dev
# 打开 http://127.0.0.1:4173

npm run build
# dist/ 只包含网页、桌面安装清单、图标、公开示例和 web/ 静态资源
```

`vercel.json` 明确设置 `npm run build` 与 `dist/` 输出目录。生产静态文件不包含 Android 工程、测试工具、个人数据、签名或 `node_modules`。本地直接打开页面无需安装 Node.js，但需要保留相邻 `web/` 资源目录。

## 验证

```bash
npm test
npx playwright install chromium firefox webkit
npm run test:browser
```

浏览器测试覆盖 Chromium、Firefox、WebKit 的导入、备份、编辑、删除、撤销、跨月切换、下班时间、草稿恢复、配额失败、跨标签冲突、无障碍和离线打开。视口检查包含 320、390、768、1440 像素宽度及 667×375 横屏，分别检查深浅色和弹层操作区域。

数据测试覆盖旧版 JSON、毫秒与时区偏移、闰年、跨年、夏令时、异步响应过期、超限输入、导出回读和大批量打卡。测试截图和失败跟踪位于被 Git 忽略的 `test-results/`，HTML 报告位于 `playwright-report/`。

WebKit 自动化不是 iPhone 真机测试；系统日期控件、文件下载确认和触屏手感仍会随设备变化。设计参考与素材来源见 [网页第三方说明](../web/THIRD_PARTY_NOTICES.md)。
